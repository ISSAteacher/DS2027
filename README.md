# Digital Society · IB DP — портал класса

Сайт для учеников IB DP Digital Society (International Steppe School of Astana).

| Группа | Юниты |
|---|---|
| **SL** | Unit 1 · Revisiting digital society |
| **HL** | Unit 1 · Revisiting digital society + Unit 2 · HL extension |

## Возможности

**Ученик** (вход по PIN):
- **Страница урока** (54 урока, 361 активити): big question, learning objectives, 3C и key terms, **кейсы для чтения** (67 кейсов — Казахстан и мир, вопросы «Think while you read», ссылки «Read more»), **мини-исследование в каждом уроке** (исследовательский вопрос, что найти, поисковые запросы, стартовые источники, 2–3 источника с оценкой надёжности, ответ на вопрос), интерактивные активити — квизы с автопроверкой, «соотнеси», «распредели», таблицы (stakeholder map, process chain, OPVL), оценка по критериям, письменные ответы с таймером и самопроверкой по markband, exit ticket, ДЗ. Ответы сохраняются автоматически.
- **Мои уроки** — уроки своего юнита/юнитов, чек-лист заданий из handout, статус, оценка, обратная связь учителя, своя рефлексия. Прогресс-бар по юниту.
- **Обсуждения** — групповые чаты, куда добавил учитель: текст, файлы любого типа до 20 МБ (PDF, Word, PowerPoint, изображения, видео…), ссылки.
- **Новости** — публикация по шаблону: заголовок, картинка, ссылка, APA 7 (собирается автоматически), связь с 3C (Content / Concept / Context + пояснения), краткое описание. Лента видна всем; **ИИ (Gemini) сам определяет тему** и HL challenge. Фильтры по теме, 3C, группе, поиск.
- **External assessment** — структура SL/HL, Paper 1, 2, 3, pre-release 2027, command terms, советы экзаменаторов, чек-лист (для SL вкладка Paper 3 скрыта).

**Учитель** (e-mail + пароль):
- **Ученики и PIN** — добавление (списком), группа SL/HL, показать/скрыть PIN, сменить PIN вручную или сгенерировать, печать карточек с PIN. Смена PIN сразу закрывает доступ по старому PIN на всех устройствах.
- **Ответы учеников** — кнопка «📝 Ответы n/m» у каждого ученика в «Прогрессе» показывает все его ответы на активити урока.
- **Прогресс и feedback** — по уроку: галочки по каждому заданию handout, статус, уровень (Beginning…Excelling), оценка (напр. 6/8), feedback, видна рефлексия ученика. Автосохранение. **Сводка** — таблица ученики × уроки с % выполнения.
- **Уроки и handouts** — редактирование списка заданий каждого урока под handout, ссылки на handout и слайды, заметка (ДЗ, дедлайн).
- **Обсуждения** — создание, выбор участников (все SL / все HL / вручную), **автоматическое разбиение на группы**, привязка к уроку, открыть/закрыть, удалять сообщения.
- **Новости** — модерация: сменить тему, перезапустить ИИ, удалить.

## Настройка (≈ 20 минут)

### 1. Firebase
1. [console.firebase.google.com](https://console.firebase.google.com) → **Create project**.
2. **Build → Authentication → Get started**, включите:
   - **Anonymous** (для учеников — вход по PIN);
   - **Email/Password** (для учителя).
   - Во вкладке **Users → Add user** создайте аккаунт учителя (e-mail + пароль).
   - Рекомендуется: **Settings → User actions** — снимите «Enable create (sign-up)», чтобы никто не мог создать себе аккаунт с e-mail.
3. **Build → Firestore Database → Create database** (регион, например `europe-west`), режим production.
4. **Build → Storage → Get started** — нужен для файлов в чате и картинок новостей. Для новых проектов Storage доступен только на тарифе **Blaze** (оплата по факту, есть бесплатная квота — для класса обычно 0 ₸). Если не хотите Blaze — поставьте `USE_STORAGE = false` в `js/config.js`: тогда ученики прикрепляют **ссылки** (Google Drive / OneDrive) вместо загрузки файлов.
5. **Build → AI Logic → Get started → Gemini Developer API** — для ИИ-категоризации новостей (работает на бесплатном тарифе в пределах лимитов). Если не включить — сработает запасной классификатор по ключевым словам.
6. **Project settings → General → Your apps → Web (</>)** → зарегистрируйте приложение и скопируйте `firebaseConfig`.

### 2. Настройки сайта
В `js/config.js`:
- вставьте `firebaseConfig`;
- `TEACHER_EMAILS` — e-mail учителя.

В **`firestore.rules`** и **`storage.rules`** замените `teacher@school.kz` на тот же e-mail.

### 3. Правила безопасности
Вариант A — через консоль: **Firestore → Rules** → вставьте содержимое `firestore.rules` → Publish. **Storage → Rules** → вставьте `storage.rules` → Publish (консоль попросит разрешить Storage читать Firestore — согласитесь).

Вариант B — через CLI:
```bash
npm i -g firebase-tools
firebase login
firebase use --add            # выберите проект
firebase deploy --only firestore:rules,storage
```

### 4. GitHub Pages
1. Создайте репозиторий, загрузите все файлы (корень репозитория = эта папка).
2. **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save.
3. Через минуту сайт будет на `https://<username>.github.io/<repo>/`.
4. Firebase → **Authentication → Settings → Authorized domains → Add domain**: `<username>.github.io`.

> `apiKey` в `config.js` — это публичный идентификатор, его можно хранить в открытом репозитории. Данные защищают правила Firestore/Storage.

### 5. Первый запуск
1. Откройте сайт → «Вход для учителя».
2. **Ученики и PIN** → вставьте список имён, выберите SL или HL → Добавить. Распечатайте карточки с PIN.
3. **Уроки и handouts** → отредактируйте задания под handout каждого урока и добавьте ссылки.
4. Ученики входят по PIN.

## Как устроен вход по PIN
- Ученик вводит PIN → анонимный вход Firebase → запись `sessions/{uid}` связывает устройство с учеником, только если PIN верный (проверяется правилами).
- Каждое правило проверяет, что PIN сессии всё ещё принадлежит ученику, — поэтому после смены PIN старые сессии сразу теряют доступ.
- PIN — 6 цифр (можно задать 4–8). Список PIN-кодов прочитать нельзя, только проверить конкретный.

## Данные (Firestore)
| Коллекция | Что хранит |
|---|---|
| `students` | имя, группа (SL/HL), PIN |
| `pins` | PIN → id ученика |
| `sessions` | устройство (uid) → ученик |
| `lessonMeta` | задания handout, ссылки, заметка по уроку |
| `progress` | `<студент>_<урок>`: задания, статус, уровень, оценка, feedback, рефлексия |
| `discussions` (+ `messages`) | обсуждения, участники, сообщения, файлы |
| `news` | новости, 3C, APA, тема (ИИ), теги |
| `answers` | `<студент>_<урок>`: ответы на активити, выполнено n/m |

## Изменить контент урока
Файлы `js/content/*.js` (кейсы и исследования — `extra-hl.js`, `extra-rev.js`), ключ урока (`hl-11`, `rev-5`…). Типы активити (`js/content/h.js`):
`C` кейс для чтения · `RS` мини-исследование · `R` чтение · `Q` квиз · `M` соотнеси · `S` распредели · `T` таблица · `X` письменные вопросы · `E` оценка по критериям · `W` письменный ответ с таймером.

## Изменить учебный план
`js/data.js`: массивы `REV` (Unit 1) и `HL` (Unit 2) — неделя, код урока, тема, задания по умолчанию. Темы для ИИ — `NEWS_THEMES`.
Модель ИИ — `AI_MODEL` в `js/config.js` (по умолчанию `gemini-3.5-flash-lite`).
